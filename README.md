# AWS Solutions Architect — Learning Journal

My personal knowledge base while working through the
[AWS Solutions Architect Learning Plan](https://skillbuilder.aws/learning-plan/EB6SVX4CTK/aws-solutions-architect-learning-plan-includes-labs/SAJSTUCC44)
on AWS Skill Builder, plus any other useful things I pick up along the way.

> Personal learning notes — not a course or an authoritative reference.

**North star:** [H2 2026 OKR](OKR-2026-H2.md) — the objective and key results this
repo is evidence for. Notes and projects reference it as `okr: H2 2026 — KRn`.

## How this repo is organized

| Folder | What goes here |
| --- | --- |
| [Learning plan](learning-plan/learning-plan.md) | Structured notes that follow the official learning plan, organized by topic. Includes the progress tracker. |
| [Labs](labs/labs.md) | Write-ups of hands-on labs: what I built, gotchas, and screenshots/links. |
| [Projects](projects/projects.md) | Working AWS-based projects (architecture, tradeoffs, Well-Architected review, walkthrough) — heavier-weight than a lab write-up. |
| [Notes](notes/notes.md) | Random, ad-hoc learnings that don't fit a specific module. Dated entries. |
| [Resources](resources/resources.md) | Cheat sheets, useful links, whitepapers, and reference material. |
| [`templates/`](templates/) | Copy-paste templates so notes stay consistent. |

## Quick start

- Starting a new module? Copy [the module template](templates/module-note.md) into the right `learning-plan/` folder.
- Finished a lab? Copy [the lab template](templates/lab-note.md) into `labs/`.
- Starting an AWS-based project? Copy [the project template](templates/project-note.md) into `projects/`.
- Learned something random? Drop a dated entry in [notes](notes/notes.md) using [the quick-note template](templates/quick-note.md).
