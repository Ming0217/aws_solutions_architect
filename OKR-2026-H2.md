# AWS OKR — H2 2026

> The north star for this repo. Everything in [[learning-plan/learning-plan|the
> learning plan]] and [[projects/projects|projects]] is evidence against these
> key results. Referenced from note frontmatter as `okr: H2 2026 — KRn`.
>
> **Focus:** practical AWS architecture capability through hands-on design and
> implementation.

## Objective

**Build strong practical AWS architecture capability so I can confidently design
secure, reliable, and scalable cloud solutions for real application use cases.**

## Key results

1. **Design and document 6 AWS solution architectures** across distinct use
   cases, with each architecture explicitly covering security, reliability,
   scalability, cost, and tradeoffs.
2. **Build 3 working AWS-based projects** that demonstrate production-relevant
   patterns such as IAM, VPC/networking, databases, compute, observability, and
   failure handling.
3. **Apply AWS Well-Architected review principles** to all 6 designs and document
   the improvements made after each review.
4. **Produce 6 concise architecture walkthroughs** that explain the design
   choices, tradeoffs, assumptions, and failure modes for each solution.

## Intent

This OKR emphasizes hands-on architectural skill, not passive learning. The goal
is to become capable of choosing the right AWS services, reasoning through
tradeoffs, designing for security and reliability, and explaining architecture
decisions clearly across multiple real-world scenarios.
